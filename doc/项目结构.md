# BookerPubTool 代码结构

ApacheCN 书籍一键发布工具：把电子书（PDF / EPUB / MOBI / AZW3）或文档站点发布到 Docker Hub / PyPI / npm / Libgen / 看云，内置知乎私信、Git 批量提交/推送，以及基于 content-pipeline 的多平台内容分发（公众号 / 小红书 / 即刻 / 抖音 / 小宇宙 / 视频号 / 微博 / B 站 / CSDN / 博客园 / 头条 / 搜狐 / 掘金）。命令行入口三个等价：`BookerPubTool`、`bpt`、`pub-tool`（见 pyproject.toml）。

代码全部位于 `BookerPubTool/` 包内，按职责分为 5 类模块：

## 1. 入口与命令注册

+ `__main__.py` — 唯一入口。构建顶层 `argparse` 解析器（`-v/--version`），遍历各平台模块调用其 `reg_subparser(subparsers)` 注册子命令，最后 `args.func(args)` 派发。
+ `__init__.py` — 包元信息（`__version__` = 2026.9.19.0，SATA 协议，作者 wizardforcel）。

## 2. 发布类命令（站点/包发布）

+ `docker.py` — `pub-docker`：站点 → Docker Hub（`apachecn0/<name>`，缺失 Dockerfile 自动生成）。
+ `pypi.py` — `pub-pypi` / `conf-pypi`：站点 → PyPI（凭据配置与过期日期跳过逻辑）。
+ `npm.py` — `pub-npm` / `conf-npm`：站点 → npm。
+ `ebook2site.py` — `ebook2site`：PDF/EPUB → 含 `index.html`/阅读器/`README.md` 的站点目录，供 `pub-*` 使用。
+ `libgen.py` — `libgen`：按系列名上传电子书到 Libgen（fiction/main 分类）。
+ `kan.py` — `kancloud`：站点 → 看云（需 `SUMMARY.md`/`README.md`）。
+ `zhihu_msger.py` — `zhihu-msg`：批量发送知乎私信（旧版/新版 Chat API）。
+ `zhihu.py` — `zhihu-crawl-uid`：从话题爬取知乎 uid。
+ `git.py` — `git-init` / `git-commit` / `git-push`：逐文件提交与推送，支持分批与子进程重启。

## 3. 内容分发类命令（社交平台）

+ `gzh.py` — `gzh`：公众号（`.md` 经 `wx_html.py` 排版为 HTML，微信 API 推草稿，失败降级手动模式）。
+ `xhs_art.py` / `xhs_img.py` / `xhs_vid.py` — `xhs-art` / `xhs-img` / `xhs-vid`：小红书纯文本/图片/视频笔记（`xhs_plrt.py` 为小红书平台共用基础）。
+ `jike_plrt.py` — `jike`：即刻（Playwright 浏览器自动化）。
+ `douyin_plrt.py` — `douyin`：抖音（实验性）。
+ `xiaoyuzhou_plrt.py` — `xiaoyuzhou`：小宇宙（Playwright）。
+ `shipinhao_plrt.py` — `shipinhao`：视频号（手动指引）。
+ `weibo.py` — `weibo`：微博（MD 转纯文本，超长自动拆分，浏览器 Cookie/扫码登录）。
+ `bili_video.py` — `bili-video`：B 站（UPOS 上传，分区/标签预测）。
+ `csdn.py` / `cnblogs.py` / `toutiao.py` / `sohu.py` / `juejin.py` — 各平台内容分发命令。

所有分发命令共用 `-p/--preview`（仅预填不发布）与 `-H/--headless`；浏览器类命令需在可见 Chromium 中手动登录对应创作者后台。

## 4. 共享基础设施

+ `wx_html.py` — Markdown → 微信公众号 HTML 排版（vendored 自 BookerMarkdownTool），`render_markdown_file()`/`render_markdown_text()`。
+ `distribute.py` — `status_print`/`hold_browser` 等发布结果打印与浏览器保持辅助（源自 content-pipeline distribute 技能）。
+ `ext_cookie.py` — 浏览器 Cookie 提取（`browser_cookie3`）。
+ `kan_util.py` — 看云工具函数。
+ `util.py` — 通用工具（`timestr` 等）。

## 5. 项目子目录

+ `doc/` — 本项目结构说明文档。
+ 根目录保留 `pyproject.toml`、`requirements.txt` 等打包/依赖配置。

关键约定与 BookerMarkdownTool 一致：每个平台模块暴露 `reg_subparser(subparsers)`，由 `__main__.py` 集中注册。
